# Idle Time Task Ideas for Claude Sessions

When not actively working on a task, here are productive things Claude can do:

## Communication & Coordination
- Check inbox for unread messages from team
- Review recent knowledge base entries for context
- Check if anyone needs help (look for blocked tasks)
- Send status updates on long-running work

## Code Quality
- Search for TODO/FIXME comments in codebases
- Look for duplicate code that could be refactored
- Check for outdated dependencies (npm outdated, etc)
- Review recent commits for missing documentation
- Look for unused files or dead code

## System Health
- Check logs for errors or warnings
- Monitor poller status (is it running?)
- Test critical endpoints/services
- Check disk space or resource usage
- Verify backups are working

## Documentation
- Document recent changes in knowledge base
- Create or update README files
- Add inline code comments where needed
- Create examples or tutorials
- Update architecture diagrams

## Proactive Improvements
- Propose optimizations for slow operations
- Suggest new features based on usage patterns
- Create helper scripts for common tasks
- Add tests for untested code
- Improve error messages

## Learning
- Review team's shared knowledge for new learnings
- Study unfamiliar parts of the codebase
- Research better approaches to existing solutions

## Quick Wins
- Fix typos in comments or docs
- Add missing .gitignore entries
- Update stale package versions
- Clean up console.logs or debug code
- Add missing error handling

---

**Usage**: Reference this list when you have idle time or between tasks to find productive work.
